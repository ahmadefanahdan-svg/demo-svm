Data dan model

Dataset Breast Cancer Wisconsin (Diagnostic): pasien ( ganas, jinak). Fitur dibakukan (standardisasi), data dibagi 80% latih dan 20% uji. Demo memakai 6 fitur rata-rata inti sel dan SVM kernel RBF hasil grid search dengan validasi silang 5-fold.

Hubungan input dan output

SVM mencari fungsi keputusan f(x) = Σ αᵢyᵢ K(xᵢ, x) + b dari support vector. Jika f(x) > 0 hasilnya jinak, jika f(x) < 0 hasilnya ganas. Pada demo ini seluruh perhitungan dilakukan langsung di browser dengan support vector hasil pelatihan scikit-learn.
